## Models

JEV-9B and JEV-27B are AutoTrust's open copies of Jev, trained on Jev's own answers. Qwen3.5-9B, untrained, is the same base model read out the same way without that training. The other rows are Jev-style models from other teams, each run through the server its authors ship. Each model name links to its model card.

Each model was asked with lettered options, the format Jev's documentation uses. A model tuned to another format may score a little lower here than in its authors' own tests.
